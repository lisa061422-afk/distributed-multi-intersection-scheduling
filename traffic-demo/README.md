# Traffic Demo

Interactive visualization for the multi-intersection robot schedules. The web
interface is implemented with HTML and JavaScript; `schedules/` contains the
saved examples used by the visualization.

On Windows, run:

```text
start_demo.bat
```

Then open `http://localhost:8080/warehouse_amr_demo_test.html`. The demo can
also be served manually with `python serve.py` from this directory.
